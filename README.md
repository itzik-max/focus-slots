# לוח סלוטי מיקוד — Itzik Oz

לוח שבו היועצות העסקיות פותחות סלוטים לפגישות מיקוד, וצוות המכירות והתיאום מסמן אילו סלוטים נתפסו.

- **כתובת:** https://itzik-max.github.io/focus-slots/
- **כניסה:** קוד צוות משותף. להגדרות צריך קוד מנהל. הקודים לא שמורים בריפו.

## איך זה עובד

```
דפדפן (GitHub Pages) ──► Supabase: פונקציות fs_* ──► טבלאות fs_settings, fs_slots
```

- **הדף** (`index.html`) הוא קובץ אחד, בלי build. הוא מתעדכן כל 15 שניות.
- **Supabase** שומר את הסלוטים ואת ההגדרות (יועצות, מיקומים, שעות).
  - הדפדפן לא קורא את הטבלאות ישירות. כל פעולה עוברת דרך פונקציה שבודקת את קוד הכניסה.
  - שתי לחיצות על אותו סלוט בו-זמנית: רק הראשונה תופסת אותו.
- **`config.js`** מחזיק את כתובת הפרויקט ב-Supabase ואת המפתח הציבורי (publishable). שניהם מיועדים לדפדפן.

## קבצים

| קובץ | מה יש בו |
|---|---|
| `index.html` | כל הלוח: עיצוב (שחור-זהב, Heebo), טאבים לפי שבועות, סיכום חודשי, הגדרות |
| `config.js` | כתובת Supabase והמפתח הציבורי |
| `supabase/schema.sql` | הטבלאות והפונקציות. אפשר להריץ שוב בלי נזק |

## משימות נפוצות

- **הוספת יועצת, מיקום או שינוי שעות:** בלוח עצמו → "הגדרות" → קוד מנהל.
- **החלפת קוד הצוות או קוד המנהל:** ב-Supabase → SQL Editor:
  ```sql
  update fs_settings set team_code = 'קוד-חדש' where id = 1;
  ```
  אחרי ההחלפה כולם יתבקשו להקליד את הקוד החדש.
- **שינוי בלוח:** עורכים את `index.html`, ואז `git push`. GitHub Pages מעלה את הגרסה החדשה תוך דקה.
