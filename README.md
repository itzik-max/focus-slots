# מערכת סלוטים – פגישות מיקוד | Itzik Oz

לוח שבו היועצות העסקיות פותחות סלוטים לפגישות מיקוד, וצוות המכירות והמשרד משריין אותם.

- **כתובת:** https://itzik-max.github.io/focus-slots/
- **כניסה:** כל אחד נכנס בקישור אישי משלו. הקישורים נמצאים אצל מנהל הלוח, תחת "הגדרות וקישורים".

## מי רואה מה

| מי | איך נכנס | מה רואה | מה יכול לעשות |
|---|---|---|---|
| מנהל הלוח (איציק) | קישור מנהל | את כל היועצות + דשבורד | הכול, כולל ניהול אנשים, קישורים, מיקומים ושעות |
| צוות מכירות ומשרד | קישור אישי | את כל היועצות + דשבורד | לשריין סלוטים. השם שלו נרשם אוטומטית על כל שריון |
| יועצת | קישור אישי | רק את הסלוטים שלה, בצבע שלה | לפתוח ולהסיר סלוטים שלה, ולראות מי שריין אותם |

ההרשאות נאכפות בשרת, לא רק במסך: יועצת לא מקבלת מהשרת סלוטים של יועצת אחרת.

## איך זה עובד

```
דפדפן (GitHub Pages) ──► Supabase (פרויקט itzik-oz-management): פונקציות fs_* ──► טבלאות fs_settings, fs_people, fs_slots
```

- **הדף** (`index.html`) הוא קובץ אחד, בלי build. הוא מתעדכן כל 15 שניות.
- **הקישור האישי** הוא `https://itzik-max.github.io/focus-slots/?k=<קוד>` (גם `#k=` עובד). הקוד נשאר בכתובת, כך שמועדפים ואייקון במסך הבית באייפון שומרים אותו.
- **אייקון למסך הבית:** `apple-touch-icon.png` (180×180) ו־`icon.svg`. באייפון: Safari → שיתוף → "הוסף למסך הבית". הלוח נפתח כאפליקציה, בלי שורת הכתובת.
- **Supabase** שומר את הסלוטים, את האנשים ואת ההגדרות.
  - הדפדפן לא קורא את הטבלאות ישירות. כל פעולה עוברת דרך פונקציה שבודקת את הקוד שבקישור.
  - שתי לחיצות על אותו סלוט בו-זמנית: רק הראשונה תופסת אותו, והשנייה מקבלת הודעה מי תפס.
- **`config.js`** מחזיק את כתובת הפרויקט ב-Supabase ואת המפתח הציבורי (publishable). שניהם מיועדים לדפדפן.

## המספרים בלוח ובדשבורד

- **נפתחו:** כל הסלוטים שהיועצות פתחו.
- **נתפסו:** סלוטים ששוריינו.
- **פנויים קדימה:** סלוטים פנויים שהזמן שלהם עוד לא עבר. אלה הסלוטים שעוד אפשר לשריין.
- **לא נוצלו:** סלוטים שנשארו פנויים והזמן שלהם עבר.
- **תפוסה:** נתפסו חלקי נפתחו.

## קבצים

| קובץ | מה יש בו |
|---|---|
| `index.html` | כל הלוח: עיצוב (שחור-זהב, Heebo, צבע מלא לכל יועצת), טאבים לפי שבועות, דשבורד, הגדרות וקישורים |
| `config.js` | כתובת Supabase והמפתח הציבורי |
| `supabase/schema.sql` | הטבלאות והפונקציות. אפשר להריץ שוב בלי נזק |

## משימות נפוצות

- **הוספת יועצת או איש צוות, שליחת קישור, החלפת קישור, מיקומים ושעות:** בלוח עצמו, בכניסת מנהל → "הגדרות וקישורים".
- **קישור שדלף:** "קישור חדש" ליד השם. הקישור הקודם מפסיק לעבוד מיד.
- **החלפת קוד המנהל:** ב-Supabase → SQL Editor:
  ```sql
  update fs_settings set admin_code = 'קוד-חדש' where id = 1;
  ```
- **שינוי בלוח:** עורכים את `index.html`, ואז `git push`. GitHub Pages מעלה את הגרסה החדשה תוך דקה.
